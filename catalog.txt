# The apps the app manager offers. One per line, fields separated by tabs:
#   id  repository  asset  file  name_en  name_fr  description_en  description_fr  [old files  [group  [recommended]]]
# id:          short and stable, names the settings and the icons (icons/<id>.bmp, icons/<id>_f.bmp)
# repository:  GitHub owner/name, whose releases publish version.txt and <asset>-<platform>.bin,
#              or codeberg:owner/name for an app whose releases are zips on Codeberg
# file:        name of the app in the applications folder, without ".app". No spaces
# old files:   earlier names of the app file, comma separated; such a file is renamed to `file`
# group:       apps of the same group do the same job and are never installed together:
#              installing one replaces the other
# recommended: "recommended" for the app of its group to choose when in doubt
